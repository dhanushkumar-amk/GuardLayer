## What is GuardLayer

GuardLayer is an open-source, self-hostable security gateway designed to protect large language model (LLM) applications from prompt injections, jailbreaks, data leakage, and toxic outputs. **Think of it like Cloudflare WAF but for LLM applications.** It intercepts incoming prompts and outgoing completions, applying configured safety filters before they reach your application users or downstream LLM providers.

### The Problem It Solves

- **Instruction Hijacking**: Stops prompts that attempt to override system rules.
- **Regulatory Penalties**: Prevents sensitive user identifiers (e.g. emails, cards, Aadhaar) from leaking to third-party APIs.
- **Brand Reputation**: Filters offensive or toxic responses generated by the model.
- **Factual Hallucinations**: Ensures responses are grounded within baseline documents.
- **Resource Abuse**: Prevents token limit exhaustion and unexpected API bills.

---

## Features

- **Prompt Injection Shield**: Blocks inputs designed to hijack system commands.
- **Jailbreak Classifier**: Detects roleplay exploits and sandbox escape patterns.
- **PII Masking**: Automatically redacts emails, cards, phone numbers, and Aadhaar numbers.
- **Semantic Topic Filters**: Restricts prompts to allowed business-related subjects.
- **Token Budget Limits**: Prevents payload size exploits.
- **Output Toxicity Scanner**: Blocks offensive or abusive content in responses.
- **Hallucination Checker**: Audits completion factual consistency against contexts.
- **Granular Config Scopes**: Links distinct safety configs to individual API keys.
- **Vibrant Analytics Dashboard**: Visualizes traffic trends, block rates, and security logs.
- **Structured Audit Streams**: Stream real-time alerts and download CSV logs.

## Quick Start

### Step 1 — Clone the Repository
```bash
git clone https://github.com/dhanushkumar-amk/GuardLayer.git
cd GuardLayer
```

### Step 2 — Configure Environment & Keys
Copy the environment template and insert your OpenAI/Anthropic keys:
```bash
cp .env.example .env
```

### Step 3 — Boot the Pipeline
```bash
docker-compose up -d
```

### Step 4 — Open the Dashboard
Open your browser and navigate to the dashboard console:
```text
http://localhost:3000
```

### Step 5 — Create an API Key
Go to the **API Keys** tab on the dashboard, click **Create Key**, name it, and copy the generated token.

### Step 6 — Route Application Traffic
Update your LLM client base URL and API key to route requests through the gateway:
```python
# Change 2 lines of code in your client initialization
openai.api_base = "http://localhost:8080/v1"
openai.api_key = "your-new-guardlayer-api-key"
```

## Integration Example

Everything else stays the same.

### Raw OpenAI SDK Example

#### Before
```python
import openai

client = openai.OpenAI(api_key="your-openai-key")
response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

#### After
```python
import openai

client = openai.OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="your-guardlayer-api-key" # GuardLayer API Key
)
response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

### LangChain Python Example

#### Before
```python
from langchain_openai import ChatOpenAI

chat = ChatOpenAI(model_name="gpt-3.5-turbo")
response = chat.predict("Hello!")
```

#### After
```python
from langchain_openai import ChatOpenAI

chat = ChatOpenAI(
    openai_api_base="http://localhost:8080/v1",
    openai_api_key="your-guardlayer-api-key",
    model_name="gpt-3.5-turbo"
)
response = chat.predict("Hello!")
```

## Configuration

Custom guard parameters can be specified via a `guardlayer.yaml` profile:

```yaml
# Global Gateway Guardrails Configuration

prompt_injection_enabled: true
prompt_injection_threshold: 0.70  # Sensitivity slider (0.0 to 1.0)

jailbreak_enabled: true
jailbreak_threshold: 0.75      # Sensitivity slider (0.0 to 1.0)

pii_scrubbing_enabled: true
pii_types:
  - email
  - phone
  - aadhaar                    # Indian national card scanner
  - credit_card

topic_filter_enabled: true
allowed_topics:
  - support
  - billing

toxicity_enabled: true
toxicity_threshold: 0.80

max_tokens: 2000               # Enforces response length constraints

hallucination_enabled: true
block_on_hallucination: false  # Log alert but do not block client response
```

For more details, see [Configuration Documentation](docs/configuration.md).

## Guards Reference

| Guard Name | Detects | Default Threshold | Can Block |
| :--- | :--- | :--- | :--- |
| **Prompt Injection** | Prompt override commands | `0.70` | Yes |
| **Jailbreak** | System bypass exploits | `0.70` | Yes |
| **PII Scrubbing** | Emails, Phones, Aadhaar, Cards | N/A | Yes (Scrubs) |
| **Topic Filter** | Off-topic query domains | N/A | Yes |
| **Toxicity** | Profanity, Hate Speech, Threats | `0.80` | Yes |
| **Hallucination** | Non-factual completions | N/A | Optional |

For a complete reference, see [Guards Documentation](docs/guards.md).

## Supported LLM Providers

| Provider Name | Models Supported | Configuration |
| :--- | :--- | :--- |
| **OpenAI** | GPT-4o, GPT-4, GPT-3.5-Turbo | Add `OPENAI_API_KEY` to env |
| **Anthropic** | Claude 3.5 Sonnet, Claude 3 | Add `ANTHROPIC_API_KEY` to env |
| **Gemini** | Gemini 1.5 Pro, Flash | Add `GEMINI_API_KEY` to env |
| **LiteLLM** | Any proxy model targets | Set `LITELLM_PROXY_URL` in env |
